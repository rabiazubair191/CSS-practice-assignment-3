# AuraGallery — Modern Photo Showcase

## 🖼️ Responsive Photo Gallery Interface

A sleek, responsive, and aesthetic photography web showcase built using pure **HTML5** and custom **CSS3**. This project focuses on modern UI layout design, Flexbox positioning, multi-page routing, clean visual hierarchy, and card elevation styling.

---

## ✨ Key Features

- **Modern Minimalist UI:** Designed with smooth drop shadows, clean typography, rounded card borders, and subtle hover states using pure CSS.
- **Categorized Multi-Page Navigation:** Built with active-state navigation tabs for seamless filtering across `All Photos`, `Nature`, `Business`, and `Abstract` pages.
- **Flexbox Layout Architecture:** Features flexible CSS Flexbox positioning and wrapped container alignments to arrange cards cleanly across screen viewports.
- **Header & Search Component Showcase:** Integrated header bar with an embedded search field and title branding for a complete UI layout feel.

---

## 🛠️ Built With

- **HTML5** (Semantic layout structure & multi-page page linking)
- **CSS3** (Flexbox alignment, box-shadow depth, custom border-radius, and UI styling)
- **Git & GitHub** (Version control and deployment)

Through this project, I strengthened my understanding of converting static layout concepts into polished web pages using pure CSS, mastering Flexbox wrapping and alignment properties, structuring uniform visual cards, and implementing multi-page active state styling without relying on external CSS frameworks.
